# 抖音评论调研工作台

本项目使用 Python 3.12、Playwright 和系统 Google Chrome，采集抖音一级评论文字及评论图片，并通过本地网页完成全部日常操作。

## 功能

- 输入抖音视频链接后启动或停止采集；
- 视频链接默认显示一个输入框，点击每行右侧的“+”新增一行（最多 100 个）；忽略空行，自动去重后逐个采集，每个视频独立保存结果和日志，单个失败继续下一个，停止整批后不再启动剩余视频；
- 遇到登录、滑块或安全验证时，由用户在 Chrome 中手动完成，再在网页点击继续；
- 评论层级可选择“仅一级评论”（默认）或“所有层级评论”；
- 一级评论默认复用浏览器捕获的真实 `comment/list` 请求按游标分页；若接口签名失效、游标不前进或请求异常，会保留已有数据并自动切回页面滚动；
- “所有层级评论”采用两阶段采集：先快速加载完全部一级评论，再回到顶部逐段展开全部回复；该模式不会因评论数或运行分钟上限自动截断；
- 保存评论文字、作者、时间、IP 属地、点赞数、回复数及评论图片；
- 可开启“获取抖音号”（默认关闭）：评论采集后，优先使用评论接口的 `unique_id`；缺失时按 `sec_uid` 去重访问用户主页，读取 `user/profile/other` 响应的 `user.short_id`，回填 `author.unique_id`。同一任务内每位用户只补充一次；额外访问主页会影响性能、增加耗时；
- `author.unique_id_source` 标记抖音号来源：`comment_api`（评论接口）、`profile_api`（主页接口）。运行日志也逐用户说明来源；未获取到时保留空值，不使用内部用户 ID 替代；
- WebP 图片自动转换为 JPEG；
- 浏览历史结果、搜索评论、仅看带图评论、按点赞数或时间排序；
- 在网页中生成并下载 Excel；
- 每次采集建立新的 `output/<时间>-<视频ID>/` 目录。

## Windows 首次安装

安装 Python 3.12 和 Google Chrome，然后在项目根目录执行一次：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e .
```

项目直接使用系统 Chrome，不需要下载 Playwright 自带的 Chromium。

## 启动与使用

双击项目根目录的：

```text
start_web.bat
```

程序会打开：

```text
http://127.0.0.1:8765/
```

之后在网页中完成采集、登录继续、停止、查看、筛选和 Excel 导出。关闭批处理命令窗口即可停止服务。

批量任务的队列、统一配置和执行状态保存到 `src/config/batch_state.json`（当前及未完成任务）。页面刷新会读取 JSON 回显，不会重复启动采集；服务重启后未完成的队列标记为已中断，不自动重跑。页面日志显示当前视频的日志，每个视频的完整日志保存在对应目录的 `run.log` 中。 运行中的批次保留完整记录，页面仅显示未完成的视频；整批结束后清除成功任务记录，全部成功则删除任务记录文件。失败、停止、未启动和中断任务继续保留，新任务不会覆盖这些记录。

本地服务只监听 `127.0.0.1`，评论和图片不会上传到外部服务器。

主要代码文件直接位于 `src/`，网页服务入口为 `src/web_console.py`。

## 数据目录

```text
output/
└── 20260916-120000-视频ID/
    ├── comments.json
    ├── comments.xlsx
    └── comment-评论ID-01.jpg
```

`.douyin-browser-profile/` 保存专用 Chrome 的登录状态，不要同时运行多个工作台实例。
